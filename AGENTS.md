# AGENTS

## Default Commenting Policy (Always On)

This repository enforces strict English commenting by default for every code change.

1. Every new source file must include a top-level English comment describing the file's exact purpose and scope.
2. Every function and method must include an English GoDoc comment that precisely explains behavior, key inputs/outputs, and side effects.
3. Every added or modified executable code line must include an inline English comment that describes the exact logic of that line.
4. Comments must be concrete and technically precise; vague comments are not allowed.
5. When code changes, related comments must be updated in the same change to keep behavior and comments consistent.

## Enforcement

- Treat this policy as mandatory, not optional guidance.
- Reject or revise changes that violate this policy before finalizing.
